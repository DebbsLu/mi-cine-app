## ｡𖦹°‧ About the Project
In this project, we learned and implemented modern mobile technologies to create a full-featured cinema ticketing ecosystem. 

The application facilitates a seamless ticket purchasing experience for moviegoers and provides a robust administrative setup for cinema staff, protected by biometric authentication.

## ᝰ.ᐟ Tech Stack
- **Framework:** React Native (Expo)
- **Language:** TypeScript
- **State Management:** Redux Toolkit & React Redux
- **Navigation:** React Navigation
- **Local Storage:** AsyncStorage (`@react-native-async-storage/async-storage`)
- **Layout:** Flexbox (React Native `StyleSheet`)
- **Hardware APIs:** 
  - Camera (`expo-camera`)
  - Biometrics (`expo-local-authentication`)

## ✨ Key Features
- **Movie Browsing & Feed:** Easily explore available movies and select the one you want to watch.
- **Seamless Checkout:** Select seats, purchase tickets, and store digital tickets directly in the app.
- **Biometric Staff Authentication:** High-security login for cinema staff utilizing hardware biometric sensors.
- **Admin Management Dashboard:** Complete CRUD functionality for staff to add, update, or delete movies and showtimes.
